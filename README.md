# Curso JS - Seminario

Proyecto con los ejemplos y actividades vistos en la clase de seminario.

## Temas cubiertos

- Cadenas de texto, metodos: concat, repeat, replace, split, substring, etc.
- Objetos, crear y modificar propiedades.
- Desestructuración de objetos.
- DOM y eventos: click, focus, keyup, change, submit, DOMContentLoaded.
- Formularios HTML con validacion.
- Bulma CSS.
